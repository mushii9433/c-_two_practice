Structure and Mechanics of a ⁠while⁠ Loop (C#)
1. General Format of a ⁠while⁠ Loop
A ⁠while⁠ loop repeatedly executes a block of code as long as a specified Boolean expression evaluates to true.  
Code Syntax:

While Clause: The first line is called the while clause.  
 Body of the Loop: Statements inside the curly braces are the body of the loop.  
 Execution Rule: When a while loop executes, the Boolean expression is tested. If true, the statements are executed.  
 Iteration: Each time the loop executes its statement or statements, we say the loop is iterating, or performing an iteration.  
 Counter Variables: Variables used to track how many times a loop runs.  
2. The ⁠while⁠ Loop is a Pretest Loop
 Pretest Loop: A while loop is a pretest loop, which means it tests its condition before performing an iteration.  
 If the condition is initially false, the statements inside the loop will not execute even once.  
 This usually means steps must be taken prior to the loop to ensure it executes at least once.
